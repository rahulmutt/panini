# ubhayapada — 1.3.72 *svaritañitaḥ* — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Discharge the ubhayapada deferral every gaṇa spec has carried since gaṇa 1 — add 1.3.72, make a root able to admit both padas, and land rudhādi's eponym √rudh.

**Architecture:** No new pipeline concept. `Context.pada` is already a *requested* coordinate that 1.3.12 / 1.3.78 sanction or block; "ubhayapadī" means only that a root gets sanctioned in **both**. The change is a three-valued `PadaAssignment` in the data layer, a `padas()` accessor that every enumeration loops over, one new sūtra (1.3.72), one widened arm (1.3.78), and an explicit pada column on the golden tables — which until now inferred pada from the root. √rudh is chosen because it needs **no new phonology at all**: its ātmanepada arm is structurally √indh's and its strong parasmaipada arm is √bhañj's and √piṣ's.

**Tech Stack:** Rust (workspace pinned to 1.97.1 via `mise`), no new dependencies.

**Spec:** `docs/superpowers/specs/2026-08-15-ubhayapada-1-3-72-design.md` (commit `8b047a0`).

**Branch:** `ubhayapada-1-3-72` (already created; the spec is committed on it).
